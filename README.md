# Padwork — тренажёр фингердрамминга (DnB / jungle / amen)

Локальное веб-приложение под Akai MPD218 и Chrome: ноты едут по экрану, ты бьёшь по пэдам,
приложение показывает «рано / поздно» в миллисекундах и ведёт счёт.

## Запуск

```
npm install
npm run dev
```

Открой в Chrome `http://localhost:5173`, подключи MPD218 по USB, нажми «Начать» и разреши доступ к MIDI.
Без контроллера работает клавиатура: `Z X C V` / `A S D F` / `Q W E R` / `1 2 3 4` (Shift — тихий удар).

Проверки: `npm test` (логика оценки, нарезки, уроков) и `npm run build`.

## Первым делом — калибровка

Раздел «Калибровка», две минуты:

1. **Звук** — стучишь по пэду в щелчок метронома; приложение берёт медиану 20 ударов и показывает разброс.
2. **Экран** — без звука, бьёшь в момент, когда метка пересекает линию.

Смещения хранятся отдельно для каждого устройства вывода, их можно поправить руками в «Настройках».
Калибруйся в тех же наушниках, в которых занимаешься.

## Как устроена честность тайминга

- Время удара берётся из `timeStamp` MIDI-сообщения (момент прихода в систему), а не из момента,
  когда до него добрался JavaScript.
- Часы урока — время `AudioContext`. Связь с часами MIDI строится по `getOutputTimestamp()`
  (скользящая медиана), то есть сравнение идёт со звуком, который реально выходит из динамиков.
- Отклонение = время удара − время ноты − калибровочный сдвиг. Больше никаких поправок.
- Окна: точно ±20 мс, хорошо ±40 мс, неточно ±70 мс. На плотных роллах окно сужается до половины
  интервала между нотами, чтобы удар не засчитывался соседней ноте.
- Точность = очки за ноты (100 / 70 / 40 / 0) минус 25 за каждый лишний удар.
- После зачёта видны гистограмма отклонений, средний сдвиг и разброс, статистика по каждому звуку.

## Задержка звука

Удар запускает уже декодированный сэмпл напрямую, без очередей; `AudioContext` создан с
`latencyHint: 'interactive'`. Остальное зависит от системы:

- только проводные наушники/колонки (Bluetooth = 100–300 мс);
- в Windows отключи «Улучшения звука» и пространственный звук у устройства вывода;
- Chrome на Windows работает через общий режим WASAPI — 10–30 мс это норма; ASIO браузеру недоступен.

Фактические цифры (буфер, задержка вывода) показаны в «Настройках».

## MPD218

По умолчанию пэды 1–16 = MIDI-ноты 36–51 (банк A заводского пресета). Если у тебя другой пресет —
«Настройки → Обучить пэды». Note Repeat и Full Level лучше выключить.

Раскладка DnB-кита (пэд 1 — левый нижний):

| | | | |
|---|---|---|---|
| 13 Tom low | 14 Tom mid | 15 Tom high | 16 Shaker |
| 9 Open hat | 10 Ride | 11 Crash | 12 Ride bell |
| 5 Hat | 6 Rim | 7 Clap | 8 Hat |
| 1 Kick | 2 Snare | 3 Snare | 4 Kick |

Кик, снейр и хэт продублированы под две руки. Ghost-ноты играются на том же пэде снейра, но тихо —
включается мягкий слой сэмпла.

## Уроки

1. Ровный пульс → 2. Базовый DnB (two-step, хэты, ghost-ноты) → 3. Amen break по тактам и целиком →
4. Чоп на слайсах → 5. Роллы.

У каждого урока лесенка темпа до 174 BPM. Следующая ступень открывается после зачёта на ≥ 85 %.
Режимы: практика (по кругу), зачёт, «послушать», «без темпа» (нота ждёт удара, тайминг не оценивается).
Можно ввести любой свой темп — такой зачёт в прогресс не идёт.

Уроки описаны данными в `src/lessons/index.ts`: строка шагов на каждый звук
(`x` — удар, `X` — акцент, `o` — ghost, `.` — пауза).

## Свой брейк

«Мой брейк»: перетащи WAV/FLAC/MP3, выбери нарезку по транзиентам или равной сеткой, поправь маркеры
на волне (перетаскивание, двойной клик — добавить, правый клик — удалить). Первые 16 слайсов ложатся
на пэды 1–16. Кит сохраняется в браузере (IndexedDB) и доступен в свободной игре и в уроках чопа.

## Подыгрыш

В «Свободной игре» и в каждом уроке есть список **«Подыгрыш»** — бас и аккорды, под которые можно играть брейк:
liquid (аккорды + саб), jungle (саб со слайдами + тёмный пэд), techstep и techstep 2 (reese-бас, ровный и
стаккато), darkstep (перегруженный reese + тревожный пэд), neurofunk (wobble-бас), jump-up (бас через октаву). Тональность — фа минор,
цикл 4 такта, темп тот же, что у урока или метронома. Рядом — ползунок громкости.

В свободной игре: выбери кит (например, Amen break), подыгрыш и нажми «Играть». В уроках подыгрыш вступает
после отсчёта; в режиме «без темпа» его нет. Подыгрыш синтезируется (поэтому идёт в любом темпе), барабаны —
по-прежнему только сэмплы. Стили описаны данными в `src/audio/backing.ts`.

## Киты и подбор звуков

В каждом уроке рядом с темпом есть список **«Кит»** — им звучат пэды во всех уроках:

- **DnB, DnB 2, Jungle, Jungle 2, Jump Up (SampleRadar)** — обработанные электронные хиты из DnB-пака SampleRadar;
- **Breakbeat-кит** и **Студийный DnB-кит** (fingerdrum.io) — живые барабаны со слоями по силе удара.

Кнопка **«Звуки…»** открывает замену отдельных звуков: для кика, снейра, хэта, райда и крэша можно выбрать
любой сэмпл из пака (42 кика, 42 снейра, 26 хэтов, 23 тарелки) — он сразу прозвучит. Выбор запоминается для кита.

Сэмплы SampleRadar нельзя распространять, поэтому в репозитории их нет. После клонирования выполни:

```
npm run samples
```

Скрипт скачает пак (≈250 МБ) с MusicRadar и положит нужные хиты в `public/kits/sampleradar`.
Без них приложение работает на китах fingerdrum.io.

Манифесты китов генерирует `python scripts/build-kits.py` — состав готовых китов SampleRadar задаётся там.

- `public/kits/sampleradar` (не в git) — хиты из **SampleRadar: drum 'n' bass essentials**

  авторы — в `public/kits/breakbeat/README.txt`.
- `public/kits/dnb` — **Drum & bass kit** с [fingerdrum.io](https://fingerdrum.io/sample-kits) (Re: TUNES).

  Авторы и ссылки — в `public/kits/dnb/README.txt`, файл нужно сохранять рядом с сэмплами.

  Подробности — в `public/kits/amen/LICENSE.md`.

Метроном — синтезированный щелчок; все барабанные звуки — сэмплы.
